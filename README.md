# Консультант по питанию

Проект персонального ИИ-консультанта для планирования питания, расчёта калорий, белков, жиров и углеводов (КБЖУ) и учёта фактически съеденного.

## Состояние проекта

Реализованы калькулятор КБЖУ и локальный дневник на Python с сохранением в SQLite. Добавлены команды запуска и автоматические проверки. Добавлен адаптер Airtable: для самостоятельного запуска нужно настроить токен среды. Живое чтение через коннектор проверено, запись адаптером проверена на тестовом клиенте. Создание окружения Codex позволяет работать с репозиторием, но не переносит автоматически настройки ассистента из ChatGPT.

## Документация

- [Правила консультанта](docs/consultant_rules.md) — требования к меню, расчётам, подтверждениям и будущей синхронизации.

## План разработки

1. Готово: калькулятор КБЖУ по массе продукта и значениям на 100 г.
2. Готово: дневной учёт с раздельными статусами PLANNED и CONFIRMED.
3. Добавлен адаптер Airtable; настройка и ограничения описаны в [инструкции](docs/airtable.md).
4. Проверить пересчёт, замену блюд, повторную синхронизацию и переход к новому дню.

## Запуск

Требуется Python 3.10 или новее. См. [инструкцию запуска](docs/usage.md).

```bash
python -m nutrition calculate examples/meal.json
python -m unittest discover -s tests -v
```

## Конфигурация и данные

Цели питания и часовой пояс должны задаваться в конфигурации. Токены, пароли, дневники питания, фотографии и медицинские сведения не размещать в публичном репозитории. Секреты будущего приложения передавать через переменные окружения.

## Работа через Codex

Сначала читать актуальные файлы и инструкции проекта. Каждое изменение сопровождать понятным описанием и проверкой, подходящей его масштабу. Не утверждать, что приложение или интеграция работают, пока это не подтверждено проверкой.
