# Проверка интеграции

Проверка 03.10.2026 (Asia/Omsk) выполнялась в отдельной базе «Питание — ТЕСТ интеграции», без копирования личных записей. Синтетическая позиция относится к 2099-01-01 и явно помечена ТЕСТ.

Сам код AirtableJournal выполнялся в Python, операции транспорта передавались подключённому коннектору Airtable. Это проверка логики адаптера на живых данных; HTTP-транспорт с PAT в отдельном окружении не использовался для записи. Успешное чтение HTTP-транспортом ранее подтверждено результатом задачи пользователя.

Пять проверок прошли:

1. Создание плана — Version 1.
2. Повтор плана — одна позиция, версия не увеличилась.
3. Подтверждение — 144 ккал, Б 32.4, Ж 0.9, У 5.4; Version 2.
4. Повтор подтверждения — одна позиция, Version 2.
5. Попытка записи со старой версией — отклонена.

Исправлены выявленные особенности Airtable: время записи задаётся до миллисекунд, отсутствие unchecked checkbox трактуется как false при проверке записи.

Основной дневник при проверке не изменялся. Тестовая база оставлена для дальнейших проверок. Автоматические тесты дополнительно проверяют расчёты, закрытый день, неверные версии, частичную запись, авторизацию API и входящие события каналов.
