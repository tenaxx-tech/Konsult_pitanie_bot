# Запуск калькулятора и дневника

Требуется Python 3.10 или новее с базой часовых поясов IANA. Сторонние библиотеки не нужны. Команды выполняются из корня репозитория.

## Пример

`examples/meal.json` содержит условный продукт. Замените название, массу и значения на 100 г данными этикетки. Укажите источник, основу массы (`raw` — сырая, `ready` — готовая) и приблизительность (`estimated`).

```bash
python -m nutrition calculate examples/meal.json
python -m nutrition --day 2026-10-02 plan breakfast examples/meal.json
python -m nutrition --day 2026-10-02 confirm breakfast
python -m nutrition --day 2026-10-02 summary
python -m nutrition --day 2026-10-02 close
```

Без `--day` используется текущая дата в часовом поясе Asia/Omsk. Другой пояс задаётся `--timezone Europe/Moscow`. Параметры `--day`, `--timezone`, `--db` указываются перед командой. Выберите один часовой пояс и одну базу для дневника.

Замена ещё не съеденного блюда:

```bash
python -m nutrition --day 2026-10-02 plan dinner examples/meal.json
python -m nutrition --day 2026-10-02 plan dinner examples/meal.json --replace
```

Повторный `confirm` не увеличивает итог и версию. Нельзя заменять подтверждённое блюдо или изменять закрытый день. Для уже съеденной новой еды сначала создайте запись `plan`, затем явно выполните `confirm`.

Данные сохраняются локально в `nutrition.sqlite3`; другую базу задаёт `--db /path/to/diary.sqlite3`. Не добавляйте личную базу в GitHub. Файл не шифруется; доступ к нему регулируется правами файловой системы.

## Результат

- `confirmed` — фактически съеденное;
- `planned` — ещё не подтверждённый план;
- `forecast` — сумма факта и плана;
- `remaining` — остаток от факта до целей, отрицательные значения показывают превышение;
- `version` и `last_update` — локальная версия и время последнего изменения;
- `meals` — блюда, порции, источники и отметки приблизительности.

БЖУ считаются с Decimal без промежуточного округления, отображаются до одного знака после запятой. Остатки рассчитываются из неокруглённых итогов. Цели можно изменить через `Goals` в Python API и передать в `Journal(goals=...)`.

## Границы текущей версии

Это локальное ядро и команды запуска, а не подключённый к ChatGPT или Telegram бот. Airtable, распознавание фотографий, каталог продуктов, изменение целей через командную строку и корректировки закрытых дней пока не реализованы. Локальная Version не является версией Airtable. Программа не определяет пищевую ценность самостоятельно: исходные значения задаёт пользователь.
