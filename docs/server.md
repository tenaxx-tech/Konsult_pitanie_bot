# Сервер API

Подготовлен `python -m nutrition.api` с Bearer-авторизацией:

- POST /calculate — расчёт порций;
- GET /day?date=YYYY-MM-DD — чтение дня и активных протоколов;
- POST /meal — явная запись одной позиции с expected_version.

Нужны AIRTABLE_TOKEN, AIRTABLE_BASE_ID и отдельный случайный NUTRITION_API_KEY длиной не менее 32 символов. Ключ сервера отличается от токена Airtable. Никогда не добавляйте значения ключей в репозиторий.

Сервер по умолчанию слушает 127.0.0.1:8080. Для внешнего доступа необходим HTTPS reverse proxy. Dockerfile запускает API; для шлюза Telegram/VK замените команду на `python -m nutrition.channels`, настройте порт и постоянный том для CHANNEL_DB. Развёртывание и HTTPS ещё не выполнены.

Схема actions/openapi.json предназначена для будущего GPT Action: перед использованием заменить YOUR_API_DOMAIN на реальный HTTPS-домен, настроить API Key / Bearer в редакторе GPT. В схеме нет секретов. Для Telegram/VK схема GPT не требуется.

Для записи CONFIRMED API требует user_confirmed=true: передавать это значение только после явного подтверждения съеденного. Для correction=true также требуется user_requested_correction=true. Эти флаги фиксируют событие, но не проверяют самостоятельно истинность утверждения пользователя. Вызов от неавторизованного клиента отклоняется.

В начальной версии каждый запрос чтения повторно получает схему и Config; при постоянном использовании понадобятся очередь, контроль нагрузки, таймаутов и мониторинг. Запись сериализована в пределах одного процесса; не запускайте параллельные писатели через несколько процессов.

## Bothub

Bothub предоставляет API моделей; в кабинете «Для разработчиков» опубликован base URL https://openai.bothub.ru/v1 и управление API-ключами. Это можно использовать в следующем этапе подключения диалога. В текущем коде LLM-клиент не реализован и обращения к платному API Bothub не выполнялись.

Проверенные страницы Bothub описывают доступ к моделям, но не подтверждают размещение произвольного Python-сервера. Для наших webhook-обработчиков необходим отдельный постоянный сервер либо платформа размещения ботов. Подписка Bothub и API-доступ не означают автоматически наличие такого сервера.
