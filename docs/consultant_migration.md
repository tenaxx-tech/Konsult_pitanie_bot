# Перенос исходного консультанта в Telegram

Полную исходную инструкцию нужно получить из настроек проекта ChatGPT.
Не восстанавливать v1.2 по резюме или файлу consultant_rules.md.
Добавить полный текст без изменения в активный Config с Key=PersonalConsultantInstructions.
Ключ необязателен: до импорта бот использует базовую инструкцию. Отсутствие текста
не означает успешного переноса. Секреты и токены не включать в инструкцию.

Общий загрузчик передаёт активные NutritionSyncProtocol, NutritionCalculationProtocol,
WeeklyPlanningProtocol, MorningBriefingProtocol и ClosingProtocol системными инструкциями
GigaChat, Gemini и Groq при каждом запросе. Произвольные ключи Config и дневник
не становятся системными инструкциями. После установки загрузчика изменения Config
не требуют пересборки.

Одинаковые инструкции не гарантируют одинаковых ответов разных моделей.
История ChatGPT, память, расписания и инструменты не переносятся автоматически.
Подключение протокола не реализует запись, замены, закрытие, баллы и расписания:
проверять эти функции отдельными сценариями. Не заявлять об исполнении без
подтверждения обработчика. Сначала проверить импорт офлайн, затем после обновления
контейнера — один план на остаток дня. Не изменять личный дневник для тестов.
