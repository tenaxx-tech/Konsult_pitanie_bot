# Подключение GigaChat API

Для личного бота используйте проект физического лица GigaChat API и его Freemium-тариф.

В BotHost добавьте секрет:

- Имя: `GIGACHAT_AUTHORIZATION_KEY`
- Значение: ключ авторизации из проекта GigaChat API (не временный access token)
- Не добавляйте значение в GitHub, сообщения или журнал сборки.

Модель по умолчанию — `GigaChat-2`. Её можно изменить через `GIGACHAT_MODEL`; доступные варианты зависят от Freemium-квоты проекта. Код получает и кеширует временный access token, срок действия которого — около 30 минут.

Для анализа фото используется `GigaChat-2-Pro` через переменную `GIGACHAT_VISION_MODEL`. Обработка изображений может тарифицироваться отдельно от текстовых сообщений и до 1792 токенов на изображение по документации провайдера. Не отправляйте через бота личные изображения, если не хотите передавать их GigaChat API. После разбора код пытается удалить загруженный файл из хранилища провайдера.

Когда включён allowlist исходящих доменов, разрешите HTTPS-запросы к:

- `ngw.devices.sberbank.ru` — получение access token;
- `api.giga.chat` — ответы модели.

В приложении нет собственного дневного лимита или задержки между сообщениями. Остаются ограничения провайдера: бесплатная квота считается в токенах, а для физических лиц предусмотрен один поток запросов. Точный расход зависит от системной инструкции, контекста Airtable, истории диалога и длины ответа. Расход можно отслеживать в кабинете GigaChat API.

Freemium предназначен для личного некоммерческого использования. Не используйте его для публичного или коммерческого бота без проверки условий тарифа.
